# Design Inspiration

Use this catalog to translate visual references into concrete, original design decisions. The URLs are third-party inspiration resources, not software dependencies or packages to execute.

## Workflow

1. **Define the design task.** Identify the product, target audience, primary user action, platform (mobile, web, or both), existing brand constraints, and desired visual direction. If critical context is missing, make reasonable assumptions rather than stalling.
2. **Choose relevant sources.** Start with 2–4 references from the catalog below based on what is actually being designed. Do not browse all ten by default.
3. **Observe before claiming.** When browsing is available, inspect real examples and record the source URL and specific useful pattern. If browsing is unavailable, treat the entries as an unverified reference directory and never claim to have reviewed the current sites.
4. **Extract principles, not finished designs.** Analyze composition, typography, color, hierarchy, whitespace, visual rhythm, animation timing, affordances, responsive behavior, and CTA placement. Do not copy proprietary illustrations, images, brands, or an entire existing layout.
5. **Make an original design plan.** Deliver an actionable specification with the chosen patterns, why they fit the audience, layout and typography direction, interaction rules, and a mobile adaptation.
6. **Build and verify.** Check content hierarchy, touch target sizing, keyboard navigation, contrast, loading performance, and reduced-motion behavior. Treat decorative animation as subordinate to usability.

## Which sources to open first

- **Landing page:** Modulify, Landdding, CTA Gallery, Godly.
- **Motion or interactive sections:** Motion in Design, then a contextual website reference from Godly.
- **Portfolio or creator site:** Reelfolio, The Internet Designs, Godly.
- **Experimental or editorial direction:** Devault ASCII, Devault Design, On Design.
- **Mobile-first product UI:** Use the above for visual language and interaction inspiration, but derive mobile navigation, hierarchy, gestures, safe areas, and accessibility from the actual platform requirements rather than assuming a website example works on a phone.

## Output format

When asked for design inspiration, return a short **reference-to-design brief**:

- **Goal:** the audience and action the interface must support.
- **References:** 2–4 source URLs and the individual pattern each contributes (only describe observed patterns if actually inspected).
- **Direction:** colors, typography, layout, spacing, imagery, component shapes, and motion principles.
- **Mobile rules:** viewport adaptation, thumb reach, minimum comfortable touch targets, text legibility, and reduced motion.
- **Originality check:** what has been transformed or recombined rather than cloned.
- **Acceptance test:** concrete checks for quality and usability.

Use `landing-page-design` in this repository for page content, conversion structure, and a visual system. Use `design-to-motion` for animations and motion showcases.
